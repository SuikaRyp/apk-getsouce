## Key Features

* **Minimalist Professional Developer UI**: Clean white and blue interface designed for mobile and desktop screens.
* **Full Source Code Extraction**:
  * **HTML Code**: Beautified code view with syntax highlighting, search, and line wrapping.
  * **JavaScript Files**: Automatic detection and extraction of inline and external scripts.
  * **CSS Stylesheets**: Automatic detection and extraction of inline and external stylesheets.
  * **Media Assets**: Visual grid for images, SVG vectors, favicons, and OpenGraph media.
* **Direct Browser Downloads**:
  * Export complete source code packages as real ZIP archives directly to your system browser.
  * Individual file downloads for HTML, combined JS bundles, and combined CSS bundles.
* **Live Responsive Web Preview**:
  * Interactive preview with desktop, laptop, tablet, and mobile viewport view switches.
* **Automated Release CI/CD**:
  * Automated compilation for Android APK, iOS IPA, and Windows EXE uploaded directly to GitHub Releases.

## Development Guide

```bash
# Clone repository
git clone https://github.com/berusigma/GetSource-Code.git
cd GetSource-Code

# Install dependencies
npm install

# Sync Capacitor platforms
npm run cap:sync
```
